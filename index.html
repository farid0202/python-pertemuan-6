Perintah Kendali: Pengambilan Keputusan & Perulangan

Tab 1 · Konsep

Memilih jalan dan mengulang pekerjaan

Sejauh ini programmu berjalan lurus dari atas ke bawah. Dengan perintah kendali, program bisa memilih perintah mana yang dijalankan (pengambilan keputusan) dan mengulang perintah berkali-kali (perulangan). Persis seperti yang kamu lakukan setiap hari.

🔀 Pengambilan keputusan

Komputer memutuskan mengerjakan atau tidak mengerjakan sebuah perintah berdasarkan kondisi. Kondisi dievaluasi menjadi True atau False. Komputer hanya masuk ke satu cabang, karena kondisi tidak bisa bernilai benar dan salah sekaligus.

🔁 Perulangan

Komputer mengulang satu atau sekelompok perintah. Ada dua jenis:

  • for: ulangi untuk setiap item dalam koleksi (jumlahnya pasti).
  • while: ulangi selama kondisi masih True (jumlahnya belum tentu diketahui).

Contoh algoritma dan flowchart

Algoritma Bilangan Genap dan Ganjil
input  : angka dari pengguna → a
output : kategori angka (genap/ganjil)

START
   INPUT a
   IF a habis dibagi 2 THEN
      OUTPUT "Angka termasuk bilangan genap"
   ELSE
      OUTPUT "Angka termasuk bilangan ganjil"
   ENDIF
END

Pada flowchart, kondisi ditulis di belah ketupat (decision). Dari belah ketupat keluar dua panah: satu untuk True (Ya), satu untuk False (Tidak). Karena alurnya bercabang, bentuk ini disebut juga percabangan.

Algoritma Menampilkan Angka
START
   INPUT angka
   WHILE angka < 5 DO
      OUTPUT angka
      angka ← angka + 1
   ENDWHILE
   OUTPUT "Program selesai"
END

Pada flowchart perulangan, ada panah yang kembali ke atas menuju belah ketupat. Selama kondisi True, alur terus berputar. Begitu kondisi False, alur keluar dari putaran.

Tab 2 · Perintah if dan if-else

Perintah if dan if-else

Python memakai kata if untuk mengambil keputusan. Kondisi ditulis setelah if, diakhiri titik dua. Perintah yang dijalankan jika kondisi True ditulis menjorok ke dalam.

if kondisi:
    instruksi
if kondisi:
    instruksi_1      # jika True
else:
    instruksi_2      # jika False
nilai = 70
if nilai > 50:
    print("Selamat anda telah lulus")
print("Program selesai")
a = 9
if a % 2 == 0:
    print("Bilangan Genap")
else:
    print("Bilangan Ganjil")

Pada contoh kiri, baris print("Program selesai") tidak menjorok, jadi bukan bagian dari if dan selalu dijalankan. Pada contoh kanan, 9 % 2 menghasilkan 1, sehingga kondisi False dan yang tampil "Bilangan Ganjil".

Tab 3 · Perintah if-elif-else

Banyak pilihan: if-elif-else

elif adalah singkatan dari else if. Dipakai saat ada lebih dari dua kemungkinan. Satu if boleh diikuti satu atau banyak elif, dan else di akhir bersifat opsional.

if kondisi_1:
    instruksi_1
elif kondisi_2:
    instruksi_2
else:
    instruksi_3
num1 = 2
num2 = 5

if num1 > num2:
    print("Angka 1 lebih besar daripada angka 2")
elif num1 < num2:
    print("Angka 2 lebih besar daripada angka 1")
else:
    print("Angka 1 bernilai sama dengan angka 2")

Python memeriksa kondisi dari atas ke bawah. Begitu menemukan kondisi True, blok itu dijalankan lalu seluruh perintah if selesai; kondisi di bawahnya tidak diperiksa lagi. Jika semua False, blok else yang dijalankan. Contoh di atas menampilkan "Angka 2 lebih besar daripada angka 1".

Urutan kondisi sangat menentukan! Karena pemeriksaan berhenti di kondisi True pertama, kondisi yang lebih sempit (misalnya nilai >= 90) harus diletakkan sebelum kondisi yang lebih luas (nilai >= 50).

Tab 4 · Perintah match-case

Mencocokkan nilai dengan match-case

match-case (Structural Pattern Matching) mencocokkan sebuah nilai dengan beberapa pola. Cocok untuk memeriksa nilai spesifik, seperti pilihan menu atau tombol, dengan tulisan yang lebih rapi daripada deretan elif.

match variabel:
    case nilai_1:
        # dijalankan jika variabel cocok dengan nilai_1
    case nilai_2:
        # dijalankan jika variabel cocok dengan nilai_2
    case _:
        # default: jika tidak ada pola di atas yang cocok
  • Garis bawah _ adalah wildcard (cocok dengan apa saja), mirip else. Letakkan di paling akhir.
  • Gabungkan beberapa nilai dalam satu case dengan | (artinya "atau").
  • Seperti if-elif, hanya case pertama yang cocok yang dijalankan.
Butuh Python 3.10 atau lebih baru Cek versimu dengan perintah python3 --version di terminal. Di pythonanywhere, pilih konsol Python versi 3.10 ke atas.
def proses_tombol(tombol):
    if tombol == "w":
        print("Maju ke depan")
    elif tombol == "s":
        print("Mundur ke belakang")
    elif tombol == "a":
        print("Belok kiri")
    elif tombol == "d":
        print("Belok kanan")
    else:
        print("Tombol tidak dikenal")
def proses_tombol(tombol):
    match tombol:
        case "w":
            print("Maju ke depan")
        case "s":
            print("Mundur ke belakang")
        case "a":
            print("Belok kiri")
        case "d":
            print("Belok kanan")
        case _:
            print("Tombol tidak dikenal")
def cek_kategori_hari(hari):
    match hari:
        case "Senin" | "Selasa" | "Rabu" | "Kamis" | "Jumat":
            print("Hari kerja")
        case "Sabtu" | "Minggu":
            print("Akhir pekan")
        case _:
            print("Nama hari tidak valid")

Tab 5 · Perulangan for

Perulangan koleksi: for

Python memakai perulangan berbasis koleksi: jumlah perulangan sama dengan jumlah item dalam koleksi (list, tuple, string, atau range).

for var in koleksi:
    perintah

for … in adalah pasangan wajib. var adalah variabel perulangan: nilainya berganti di setiap iterasi (satu putaran), mulai dari item ke-0 sampai item terakhir. Setelah semua item terpakai, perulangan selesai.

kota = ["Solo", "Jogja", "Jakarta"]
for k in kota:
    print(k)
Solo
Jogja
Jakarta

Fungsi range

range menghasilkan deretan bilangan bulat yang bisa dipakai di for. Untuk melihat isinya, ubah dulu menjadi list dengan list().

Tab 6 · Perulangan while

Perulangan kondisional: while

while menjalankan perintah berulang-ulang selama kondisi masih True. Kondisi diperiksa sebelum setiap putaran. Begitu kondisi False, perulangan berhenti.

while kondisi:
    perintah
angka = input("Masukkan angka: ")
angka = int(angka)
while angka < 5:
    print("Angka yang ditampilkan:", angka)
    angka += 1
print("Program selesai")

Bahaya: infinite loop

Jika kondisi tidak pernah menjadi False, program berputar terus tanpa henti. Ini disebut infinite loop.

nilai = 5
while nilai > 0:
    nilai += 1          # nilai makin besar, selalu > 0
    print("Angka :", nilai)
nilai = 5
while nilai > 0:
    print("Angka :", nilai)
    nilai -= 1          # nilai makin kecil, akhirnya 0
Tiga hal yang wajib ada di perulangan while (1) variabel diberi nilai awal sebelum while, (2) kondisi yang suatu saat bisa False, (3) perintah di dalam blok yang mengubah variabel ke arah kondisi False. Kalau programmu terjebak infinite loop di terminal, tekan Ctrl+C.

Tab 8 · Wrap-up

Rangkuman perintah kendali

Selamat, kamu sudah sampai di akhir materi!

PerintahBentukPakai saat…
ifif kondisi:Ada perintah yang hanya dijalankan jika kondisi True
if-elseif …: / else:Ada dua pilihan: True atau False
if-elif-elseif …: / elif …: / else:Banyak pilihan, terutama rentang nilai. Urutan kondisi penting!
match-casematch x: / case …: / case _:Mencocokkan nilai spesifik (menu, tombol, nama hari)
forfor x in koleksi:Mengulang untuk setiap item list, tuple, string, atau range
whilewhile kondisi:Mengulang selama kondisi True; jumlah ulangan belum pasti
✍️

Aturan penulisan

Baris if, elif, else, match, case, for, while diakhiri titik dua. Blok di bawahnya menjorok.

⚖️

Kondisi

Dibuat dari perbandingan, logika (and or not), dan keanggotaan (in). Nol, None, dan koleksi kosong dianggap False.

🔢

range

range(start, stop, step) berhenti sebelum stop. Start default 0, step default 1.

♾️

Hindari infinite loop

Pastikan variabel di dalam while berubah ke arah yang membuat kondisi False.
